Um jogo simples de adivinhação em que o usuário tenta descobrir o número secreto sorteado aleatoriamente pelo sistema.

Projeto criado durante o curso **[Lógica de Programação: Explore Funções e Listas](https://www.alura.com.br)** da Alura, como prática de lógica, manipulação de DOM e estruturação de páginas web.

## 🎮 Funcionalidades

- 🎲 Sorteio de um número secreto de 1 a 1000
- ✅ Verificação automática do palpite (maior, menor ou correto)
- 🔢 Exibição do número de tentativas
- 🔄 Botão para reiniciar o jogo
- 🚫 Garantia de que não repete números já sorteados

---

## 🧠 O que aprendi com este projeto

- Manipulação do DOM com JavaScript puro
- Uso de estruturas de repetição e condicionais para controlar o fluxo do jogo
- Geração de números aleatórios sem repetição
- Boas práticas de organização de código em HTML, CSS e JS separados
